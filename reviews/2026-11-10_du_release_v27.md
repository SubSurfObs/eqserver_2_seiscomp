## Checked and found OK

- **Level 1 indexing:** the new filename rule indexes 7,519 GLDS files and
  31,366 THS files as waveform miniSEED with their explicit channel suffix;
  none is excluded. The observed ranges are GLDS SHZ from 2017-05-12 through
  2018-05-14, THS SHZ through 2019-01-28, and THS BHZ from 2019-01-29. This
  exactly supports the two reviewed plans' epoch boundary.
- **Plain record reader:** a non-ZIP file is admitted only when its miniSEED
  fixed-header quality byte is one of `D/R/Q/M`. The production adapter then
  uses the existing miniSEED record scanner and reader. It does not guess from
  the unusual `.pn.01` suffix alone.
- **Naming:** production output contains only `DU.GLDS.01.SHZ`,
  `DU.THS.01.SHZ` and, after the documented transition,
  `DU.THS.01.BHZ`. All source sampling rates and header channel names are
  preserved.
- **THS duplicate copies:** a SUDS population does sometimes outrank the
  corresponding named miniSEED population: 59 THS days in 2017, 170 in 2018
  and 12 in 2019. The miniSEED copy wins on the other days where both occur,
  and every lower-ranked copy remains authorized for gap fill. This is sound
  because both formats map to the same reviewed final identity for their era.
  In addition to the supplied 2019 example, I checked a SUDS-winning event on
  2017-06-17: both source files have the same start, 200 Hz rate, 48,000
  samples and every payload value identical. The staged SDS contains all
  48,000 values exactly once and byte-for-value matches both copies. No
  priority change or rebuild is needed.
- **Foreign-station guard:** a mixed file retains this station's traces and
  drops/records only foreign traces. A file containing only another station
  returns no data plus a loud read error. The auditor independently applies
  the same station ownership rule. This closes v2.6 F3 without relabelling
  foreign data into the target station.
- **Proof days:** all six supplied proof days genuinely compare decoded
  payloads. Across them, 11,473,500 converted samples were compared, with zero
  bad samples, zero missing seconds and zero selection loss. The remaining
  location/band findings are the expected reviewed header identities.
- **Production queue:** six clean completion records cover 1,229 `ok` days and
  zero failed or QC-flagged days. Every manifest has the intended committed
  release identities and selection hash. For every station-year, the staged
  file inventory exactly equals the manifest inventory; there are no extra or
  missing files.
- The old station databases remain separately recoverable under
  `~/station_dbs_pre_pn/`; origin data was only read. The reviewed diff adds no
  plan-gate bypass, unpinned production path or long-term write path.
