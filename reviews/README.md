# Reviews

Independent Codex reviews of Claude's work, one file per review:
`YYYY-MM-DD_<short-sha-or-topic>.md`.

Each file has two parts:

1. **Findings** — written by Codex (read-only, following `docs/review_brief.md`).
2. **Response** — appended by Claude: each finding marked
   `ACCEPTED (fixed in <sha>)`, `REBUTTED (evidence: …)` or `OPEN (needs Dan)`.

Dan reads these directly. Over time this folder is the record of which
assumptions about the conversion have actually been tested.
