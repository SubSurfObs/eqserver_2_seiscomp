# Metadata Links

External metadata sources for station network/recorder mapping.
Add URLs here; Claude will fetch and use them to populate `station_registry.yaml`.

## Format

```
## Source name
- URL: <url>
- Type: <fdsn-stationxml | seiscomp-inventory | spreadsheet | other>
- Coverage: <which stations or networks this covers>
- Notes: <anything relevant>
```
